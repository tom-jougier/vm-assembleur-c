# Projet Simulateur et Assembleur

Ce projet propose une suite d'outils comprenant un **assembleur** et un **simulateur de processeur**. Développé en langage C, il permet de traduire des instructions d'assemblage en code machine, puis de simuler l'exécution de ces instructions au sein d'un processeur virtuel.

## Structure du Projet

Le dépôt est organisé de la manière suivante :

*   **`src/`** : Contient l'intégralité du code source du projet (assembleur et processeur).
*   **`docs/`** : Contient la documentation détaillée (guides utilisateurs et techniques).
*   **`resources/`** : Regroupe les différents jeux de tests et ressources nécessaires à la validation du simulateur.

## Documentation

Pour ne pas surcharger cette présentation, tous les détails d'installation, d'utilisation et de fonctionnement technique sont déportés dans le dossier `docs/`. 

Vous y trouverez deux fichiers essentiels :
*  **`docs/user.pdf`** : Le manuel d'utilisation pour apprendre à compiler et utiliser l'assembleur et le simulateur avec vos propres fichiers de test.
*  **`docs/dev.pdf`** : La documentation développeur expliquant les choix d'architecture, la structure du code et le fonctionnement interne du simulateur.

Nous vous invitons fortement à consulter ces documents avant de commencer à utiliser ou modifier le projet !
